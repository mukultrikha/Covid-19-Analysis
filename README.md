# Covid-19-Analysis
This project analyzes COVID-19 data from around the world and India to understand the trends in confirmed cases, deaths, and recoveries. The project uses data analysis, interactive visualizations, and time series forecasting to study the spread of the virus and predict future cases.

### Key Points

- Analyzed COVID-19 confirmed, death and recovery data
- Visualized infection and recovery trends
- Created interactive visualizations using Plotly
- Used Pandas to work with multiple data files
- Built time series models using Facebook Prophet
- Forecasted future COVID-19 cases
